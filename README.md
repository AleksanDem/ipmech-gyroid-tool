# IPMech Gyroid Tool (TPMS Mesh Generator)

Интерактивный генератор трижды периодических поверхностей минимальной энергии (TPMS — Triply Periodic Minimal Surfaces) типа **Gyroid** для 3D-печати и конечно-элементного моделирования (CAE / Abaqus).

Разработано в лаборатории механики технологических процессов и новых материалов **ИПМех РАН**.

---

## 🚀 Возможности
- **Двухрежимная топология:**
  - *Solid Wall (Стенка с толщиной)*: объемная твердотельная изоповерхность с автоматической герметизацией торцов (watertight manifold mesh).
  - *Zero-thickness Sheet (Поверхность нулевой толщины)*: изоповерхность в 1 слой треугольников для вазового/поверхностного режима печати (Cura Surface Mode / PrusaSlicer Open Mesh).
- **Потоковый Marching Cubes & Binary STL Exporter:**
  - Потоковая генерация и экспорт полигональной сетки на диск без переполнения оперативной памяти (поддержка сеток > 30 млн полигонов).
- **Интерактивный 2D-срез (XY-плоскость):**
  - Мгновенный предпросмотр морфологии пор и толщины стенок на базе Plotly Heatmap.
- **Двуязычный интерфейс:** Поддержка русского (RU) и английского (EN) языков.
- **Расчет характеристик в реальном времени:**
  - Габариты $X \times Y \times Z$, число ячеек, объем, расчетная масса при заданной плотности материала $\rho$, относительная плотность (volume fraction).

## 📦 Установка и локальный запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/<YOUR_USER>/ipmech-gyroid-tool.git
cd ipmech-gyroid-tool

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить приложение
streamlit run app.py
```
