# IPMech TPMS Lattice Tool

Интерактивный генератор трижды периодических минимальных поверхностей (**TPMS** — Triply Periodic Minimal Surfaces) для 3D-печати и конечно-элементного моделирования (CAE / Abaqus).

Разработано в лаборатории механики технологических процессов и новых материалов **ИПМех РАН**.

---

## 💎 Поддерживаемые TPMS структуры
1. **Gyroid (Schoen G):** Изотропная структура с непрерывными спиральными каналами.
2. **Diamond (Schwarz D):** Высочайшая прочность и модуль упругости на осевое сжатие.
3. **Primitive (Schwarz P):** Кубическая симметрия с прямолинейными открытыми ортогональными порами.
4. **Neovius:** Повышенная площадь удельной поверхности для теплообмена и фильтрации.
5. **I-WP (Schoen):** Оптимальна для высоких плотностей и ударостойких сэндвич-панелей.

---

## 🚀 Возможности
- **Автоматическая калибровка толщины стенки:** Градиент $|\nabla F|$ рассчитывается аналитически для каждой решетки, гарантируя физическую точность толщины стенок в миллиметрах.
- **Интеллектуальная фильтрация:** Автоматическое отсечение мелких изолированных уголков и несвязных фрагментов на границах куба (`ndimage.label`).
- **Интерактивный 2D-срез (XY-плоскость):** Мгновенный предпросмотр морфологии пор и толщины стенок на базе Plotly Heatmap.
- **Интерактивный 3D-предпросмотр:** Быстрый рендеринг упрощенной модели с Gouraud-шейдингом.
- **Двуязычный интерфейс:** Полная поддержка русского (RU) и английского (EN) языков.
- **Экспорт в STL:** Генерация монолитных герметичных сеток (watertight manifold) с именованием файла по параметрам геометрии.

## 📦 Установка и локальный запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/AleksanDem/ipmech-gyroid-tool.git
cd ipmech-gyroid-tool

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить приложение
streamlit run app.py
```
